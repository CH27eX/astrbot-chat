# AstrBot Chat 0.2.26 安装与配置指南

> 版本：**0.2.26**（2026-11-23 构建）
> 适用：Windows 10/11 x64、Ubuntu 24.04 / Debian 12 amd64、Android 7.0+、iOS 15+
> 对应安装包与校验和见交付包的「安装包」目录（`SHA256SUMS.txt`）

---

## 1. 先弄清楚：这个客户端需要什么

AstrBot Chat 是 **AstrBot 的聊天客户端**，不是 AstrBot 本体。

- **客户端**：负责界面、聊天、语音、图片、手机访问；
- **AstrBot**：真正接大模型、管人格与记忆、连 QQ 的服务端，需要你已经装好并能打开它的面板。

所以装客户端之前，请先确认：

1. **AstrBot 已经能跑**：浏览器能打开面板（默认 `http://127.0.0.1:6185`，端口以你的配置为准）；
2. **已经建好一个 API Key**：面板 → `API Keys` → 新建，scope 至少勾 **`chat` + `file`**
   （想用「记忆」抽屉再勾 `plugin`），复制出来的 `abk_...` 待会儿要填；
3. **知道 AstrBot 跑在哪**：和客户端同一台电脑（推荐，客户端会自动发现端口），
   还是在另一台机器 / 虚拟机 / Docker 里（要手填地址）。

三种常见部署：

| 场景 | 客户端在哪里 | 需要填什么 |
|---|---|---|
| 全部在本机（最常见） | Windows / Linux 桌面 | API Key；地址留空自动发现 |
| AstrBot 在另一台机器 / 容器 | 桌面端 | API Key + AstrBot 地址（如 `http://192.168.1.20:6185`） |
| 手机连电脑 | Android / iOS | 电脑端打开「手机访问」，扫码或粘贴 `https://<IP>:8789/?t=…` |

## 3. Windows 安装与配置

### 3.1 安装

1. 双击 `AstrBot-Chat_0.2.26_x64-setup.exe`；
2. 如果弹出「Windows 已保护你的电脑」→ **更多信息 → 仍要运行**
   （安装包没有购买代码签名证书，不是病毒）；
3. 一路下一步。装到 `%LOCALAPPDATA%\AstrBot Chat`，**当前用户安装，不需要管理员权限**；
4. 从桌面或开始菜单打开 **AstrBot Chat**。

> 静默安装（批量部署用）：`"AstrBot-Chat_0.2.26_x64-setup.exe" /S`

### 3.2 第一次配置

打开后点左下角 **设置**，进 **桌面** 这一页：

| 字段 | 怎么填 |
|---|---|
| AstrBot 地址 | AstrBot 在同一台电脑 → **留空**（自动发现端口）；在别的机器 → `http://那台机器:6185` |
| AstrBot 数据目录 | 一般**留空**（自动找历史库）；AstrBot 在容器 / 远端 → 填挂载出来的 `data` 目录 |
| API Key | 粘贴第 1 节建好的 `abk_...`，点保存（保存后后台服务会自动重启） |

保存后回到聊天页，发一句「在吗」，能收到回复就通了。

### 3.3 确认「真的能用」

按顺序看三处：

1. 聊天能收发、能流式显示；
2. 打开一个**老会话**，能翻到之前的聊天记录（不只是最近几条）；
3. 历史诊断返回 `ok: true`：

```powershell
curl.exe -s http://127.0.0.1:8788/astrbot/api/db-status
```

- `ok: true`：看 `path`（实际读的库）和 `source`（`pid` / `port` / `settings` 等，都正常）；
- `ok: false`：`reason` 会说清哪个路径不对，`candidates` 是试过的全部路径。
  远端 / Docker 用户把**映射出来的**数据目录填进「AstrBot 数据目录」（支持 `~/astrbot/data`）。

### 3.4 数据放在哪

| 内容 | 位置 |
|---|---|
| 程序 | `%LOCALAPPDATA%\AstrBot Chat\` |
| 配置（`settings.json`，含 Key 与配对令牌） | `%APPDATA%\com.astrbot.chat\` |
| 数据 / 日志 | `%LOCALAPPDATA%\com.astrbot.chat\`（日志在 `logs\`） |

## 4. Linux 安装与配置（.deb）

适用：**Ubuntu 24.04 / Debian 12 或更新、amd64**。

```bash
# 推荐：让 apt 顺手补齐依赖
sudo apt install "./AstrBot-Chat_0.2.26_amd64.deb"

# 或者
sudo dpkg -i "./AstrBot-Chat_0.2.26_amd64.deb"
sudo apt -f install          # 缺依赖时补
```

- 装到 `/usr/bin/astrbot-chat`，应用菜单里有「AstrBot Chat」；
- 依赖：`libwebkit2gtk-4.1-0`、`libgtk-3-0`、`libayatana-appindicator3-1`（deb 已声明）；
- **自带 Node 24**（`/usr/lib/AstrBot Chat/sidecar/node`），系统不需要另外装 Node。

启动：

```bash
astrbot-chat
```

配置步骤和 Windows 完全一样（设置 → 桌面 → API Key；地址可留空）。校验连接：

```bash
curl -s http://127.0.0.1:8788/astrbot/api/db-status
```

- 配置：`~/.config/com.astrbot.chat/settings.json`
- 数据 / 日志：`~/.local/share/com.astrbot.chat/`
- 卸载：`sudo apt remove astr-bot-chat`（想连配置一起删，再 `rm -rf ~/.config/com.astrbot.chat ~/.local/share/com.astrbot.chat`）

> GNOME 下托盘图标看不到是正常的：需要 `gnome-shell-extension-appindicator`，不影响聊天。

## 5. Android 安装与连接

APK 是**签名 release 包**，和桌面端共用同一套前端，额外做了三件事：
自带桌面图标 / 启动图 / 返回键处理，地址存在 App 里，只信任你这台电脑的自签证书。

### 5.1 安装

1. 把 `AstrBot-Chat-0.2.26-universal.apk` 传到手机（微信文件传输 / 数据线 / 网盘都行）；
2. 点开安装，允许「安装未知来源应用」；
3. vivo / iQOO 等机型可能弹「应用安装拦截」→ 点 **继续安装**。

> 如果手机上装过更早的 **debug 包**，签名不同，先卸载再装。卸载会清掉 App 里存的连接地址，装完重新连一次。

### 5.2 第一次连接（只做一次）

1. 电脑上打开 AstrBot Chat → 设置 → 桌面 → **手机访问** → 打开「允许局域网访问」；
2. 电脑上会显示一条 `https://<电脑IP>:8789/?t=<令牌>` 链接和二维码；
3. 手机打开 App，把链接粘进「电脑地址」，点 **连接**；
4. 连上后直接进会话列表，之后不用再填。

> `?t=` 就是访问令牌，**别截图外传**。也可以只填 `IP:8789`，再单独填 32 位令牌。

**Android 不需要装系统证书**：自签 CA 已经打进 APK，只信任你电脑上的那张。

### 5.3 连不上按这个顺序查

| 现象 | 先看 |
|---|---|
| 一直「未连接」 | 手机和电脑是不是同一个 Wi-Fi（热点也行） |
| 连接超时 / 报错 | 电脑上「允许局域网访问」开着没？Windows 防火墙要放行**专用网络** |
| 昨天能用今天不行 | 电脑换了网络、IP 变了 → 电脑上重新开一次手机访问，拿新链接，App 里「换一台电脑」重填 |
| 打开是白屏 | 电脑上的 AstrBot Chat / 后台服务没在跑，或 AstrBot 本体没起来 |

### 5.4 界面速览

| 界面 | 说明 |
|---|---|
| 会话列表 | 头像 + 名字 + 预览 + 时间；红点是未读 |
| 聊天页 | 头部「返回 + 名字/在线 + ⋯」；`⋯` 里是记忆、聊天设置、换头像、更多设置 |
| 设置 | 从**左边缘往右滑**呼出抽屉 → 「设置」进全屏设置页 |
| 返回键 | 先关浮层 → 关抽屉 → 关设置 → 回列表；在列表上再按一次才退出 |

> 备注 / 置顶 / 归档 / 删除会话目前在**桌面端**操作。

## 6. iOS 安装与连接

### 6.1 先拿到 ipa

iOS 的安装包必须用 macOS 上的 Xcode 编译签名，**Windows 上无法直出**。
仓库里的 `ios/` 是可编译的 Xcode 工程：

- 有 Mac：`pnpm install && bash scripts/build-ios.sh` → `build/ios/AstrBot-Chat_0.2.26_unsigned.ipa`；
- 没有 Mac：把工程推到 GitHub，跑仓库里的 **iOS IPA** workflow（macOS runner），从 Artifacts 下载 ipa。

详细步骤见包内 `docs/TESTER-GUIDE-IOS.md`。

### 6.2 安装未签名 ipa

1. 电脑装 [Sideloadly](https://sideloadly.io/)（Windows / macOS 都有）；
2. 手机连电脑，Sideloadly 里选 ipa，填自己的 Apple ID，Start；
3. 手机上「设置 → 通用 → VPN与设备管理 → 开发者 App」**信任**自己的证书；
4. 免费 Apple ID 的签名 **7 天有效**，到期重签即可（App 内数据不丢）。

### 6.3 首次连接（和 Android 类似，但多一步证书信任）

1. 电脑端：设置 → 桌面 → 手机访问 → 打开「允许局域网访问」；
2. 手机 Safari 打开 `http://<电脑IP>:8788/ca.cer` 下载描述文件 → 设置里安装；
3. **设置 → 通用 → 关于本机 → 证书信任设置** → 把 `AstrBot Chat Local CA` 打开（完全信任）；
4. 打开 App，粘贴 `https://<电脑IP>:8789/?t=<令牌>`；
5. 首次会弹「查找并连接本地网络上的设备」→ **允许**。

> 第 3 步不做，App 会一直白屏或连不上。

### 6.4 iOS 的限制

- 主动消息只在 App 前台轮询，切后台 / 杀进程收不到（没有推送通道）；
- 没有自动更新，换版本要重新签装；
- 主题、表情包、记忆抽屉与桌面端一致。

## 7. 设置项详解

设置分四页（手机端是全屏分组页，桌面端是弹层）：

### 7.1 通用

| 项 | 说明 |
|---|---|
| 用户名 | 对应 AstrBot 里的身份（默认 `astrbot`）；要和身份桥 / 记忆插件的用户名一致，否则记忆不共享 |
| 通知 | 开启后，页面在后台时收到新消息会弹系统通知 |
| 备份与迁移 | **导出配置**（外观 / 机器人 / 背景图库 / 桌面连接设置，**不含 API Key**）、**导入配置** |
| 换一台电脑 / 换访问地址 | 手机端重新填地址的入口 |

### 7.2 外观

- 主题：深色 / 浅色；
- 强调色：天蓝、黛紫、青绿、湖蓝、暖橙、绯红，也可以自定义色值；
- 字号：小 / 中 / 大；密度：舒适 / 紧凑；
- 圆角：直角 / 默认 / 圆润；
- 聊天背景：内置图库或自己的图，支持压暗、虚化、换图。

### 7.3 机器人

- 机器人名字、头像；头像可以上传，也可以恢复默认。

### 7.4 桌面（仅桌面端显示）

| 项 | 说明 |
|---|---|
| AstrBot 地址 | 留空自动发现；远端填 `http://IP:端口` |
| AstrBot 数据目录 | 历史库所在目录，留空自动找 |
| API Key | `abk_...`，只存在本机配置里，不会进浏览器 |
| 手机访问 | 开关 + 二维码 + 复制链接 + 重置配对 |
| 远程地址 | 用 Tailscale Serve / 反代时填，二维码和链接会改用这个地址 |
| 排障 | 一键诊断包（日志 + 环境信息，Key 与令牌已打码） |

### 7.5 聊天设置（聊天页 `⋯`）

图片识别、语音消息、表情包、朗读回复四个开关，按需打开。

## 8. 手机访问与远程访问

### 8.1 局域网（默认）

1. 电脑端打开「允许局域网访问」；
2. 手机连同一个 Wi-Fi；
3. 扫码或粘贴 `https://<IP>:8789/?t=…`。

端口说明：`8788` 是桌面壳自己用的 HTTP 端口（只监听本机），打开手机访问后会额外监听
`8789`（HTTPS，自签证书）。**不要把 8788 直接映射到公网**——它不是给外部用的。

### 8.2 用浏览器 / PWA 打开时

只有 App（Android / iOS）才内置了 CA。用手机浏览器打开 `https://<IP>:8789` 时，
要先装一次证书：浏览器访问 `http://<电脑IP>:8788/ca.cer` → 安装 →
Android「设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书」；iOS 再到「证书信任设置」完全信任。

### 8.3 重置配对

手机丢了、二维码外泄：电脑端 **重置配对**（需确认）。会换新令牌并重启服务，
**所有手机都要重新扫**。

### 8.4 远程访问（不在同一局域网）

推荐 Tailscale：电脑和手机加入同一个 tailnet，电脑端在「远程地址」里填
`https://<机器名>.ts.net`（或 Serve 出来的地址），二维码就会直接给出可远程访问的链接。
不建议把端口直接暴露到公网。

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| Windows 提示「已保护你的电脑」 | 安装包没有代码签名 | 更多信息 → 仍要运行 |
| 一直「连不上 AstrBot」 | AstrBot 没启动 / 面板没开 / 换了端口 | 先确认浏览器能打开面板；远端就填地址；容器要映射端口 |
| 填 Key 后 401 / Key 无效 | 复制少了字符、Key 被删、scope 没勾 | 重建 Key，勾 `chat` + `file`（+`plugin`） |
| 聊天正常但历史为空 | 读不到本地 `data_v4.db` | 看第 3.3 节的 `db-status`；远端把数据目录填上 |
| 语音发不出去 / 录不了音 | 非安全上下文（http） | 用 `https://<IP>:8789` 那条地址，或改用 App |
| 手机提示「证书无效」 | 电脑换了 Wi-Fi / IP | 电脑上重开一次手机访问拿新链接；浏览器用户重装一次 CA |
| 收不到主动消息通知 | 页面被关掉 / 系统限制后台 | App 在前台才轮询；关掉后收不到属于已知限制 |
| Linux 依赖报错 | 系统太老或架构不对 | 确认 Ubuntu 24.04+ / Debian 12+、amd64，`sudo apt -f install` |
| GNOME 没有托盘图标 | 缺 AppIndicator 扩展 | 装 `gnome-shell-extension-appindicator`，不影响聊天 |
| 手机连不上但电脑能上 | 防火墙 / 不在同一网络 | 放行「专用网络」，或改用 Tailscale 远程地址 |

## 10. 升级、卸载与备份

### 升级

- Windows：直接运行新版安装包覆盖安装，配置与会话缓存都保留；
- Linux：`sudo apt install "./AstrBot Chat_<新版本>_amd64.deb"` 覆盖安装；
- Android：安装同签名的更高版本 APK 即可覆盖；换签名（debug ↔ release）必须先卸载；
- iOS：重新构建并自签安装，覆盖旧的即可。

### 卸载

| 平台 | 卸载 | 想清干净再加 |
|---|---|---|
| Windows | 设置 → 应用 → 卸载 AstrBot Chat | 删 `%APPDATA%\com.astrbot.chat` 和 `%LOCALAPPDATA%\com.astrbot.chat` |
| Linux | `sudo apt remove astr-bot-chat` | `rm -rf ~/.config/com.astrbot.chat ~/.local/share/com.astrbot.chat` |
| Android | 长按图标卸载 | 卸载即清数据 |
| iOS | 长按图标删除 | 删除即清数据 |

### 备份

设置 → 通用 → **导出配置**（不含 API Key）。换电脑 / 换地址时导入即可。
聊天记录不在客户端里，在 AstrBot 的 `data_v4.db`，备份 AstrBot 的数据目录才是备份聊天。

## 11. 隐私与安全

- **API Key 只在本机**：由本地后台服务注入请求，不写进浏览器存储、不进前端包；
- **局域网令牌**：保存在本机 `settings.json`，二维码 60 秒自动收起；
- **自签 CA 私钥**：只在本机，装到设备上的只是公钥证书；
- **数据不上传第三方**：客户端只和你的 AstrBot 通信（除非你自己在 AstrBot 里接了外部服务）；
- 不要把 `?t=` 链接、`settings.json`、诊断包里的 Key 贴到公开场合。

## 12. 出问题怎么反馈

请带上这四样：

1. 系统 / 机型与版本（Windows 版本、`lsb_release -a`、手机型号 + Android/iOS 版本）；
2. 客户端版本号（设置 → 关于，应为 `0.2.26`）；
3. 电脑端 **设置 → 桌面 → 排障 → 导出诊断包**（Key 和令牌已打码）；
4. 出错时的截图或录屏，以及第 3.3 节的 `db-status` 输出。

反馈模板见包内 `反馈模板.md`。**别把 API Key（`abk_...`）贴出来。**
