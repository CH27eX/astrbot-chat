## 1. 这是什么

一个 **Android 套壳版**（Capacitor + 系统 WebView）：界面和手机浏览器打开的 AstrBot Chat 是同一套，
但多了三件 PWA 做不到的事：

- **不用装系统证书**：自签 CA 打进 APK 里，只信任你这台电脑上的那张；
- **有 App 骨架**：桌面图标、启动图、系统返回键；
- **地址存在 App 里**：第一次填一次，之后直接进聊天。

**前提**：手机和跑 AstrBot 的电脑要连**同一个 Wi-Fi**（或同一个热点），电脑上的桌面版 AstrBot Chat 开着。

## 2. 安装

1. 把 `AstrBot-Chat-0.2.24-universal.apk` 传到手机（微信文件传输 / 数据线 / 网盘都行）；
2. 点开安装，允许「安装未知来源应用」；
3. 部分机型（vivo / iQOO）会弹「应用安装拦截」，点 **继续安装** 才装得上。

> 从旧版 **debug 包** 换过来要先卸载（签名不同，直接覆盖会失败）；卸载会清掉 App 里存的连接地址。

---

## 3. 第一次连接（只做一次）

1. 电脑上打开 AstrBot Chat → 侧栏 **设置** → 桌面 → **手机访问** → 打开「允许局域网访问」；
2. 复制那条 `https://<IP>:8789/?t=<令牌>` 链接（或扫二维码拿到同样的内容）；
3. 手机上打开 App，把链接粘进**「电脑地址」**，点 **连接**；
4. 连上后直接进会话列表，之后不用再填。

> 链接里的 `?t=` 就是访问令牌，**别截图转发**。只填 `IP:8789` 也行，那时候要在下面单独填 32 位令牌。

**连不上按这个顺序查**：

| 现象 | 先看 |
|---|---|
| 一直「未连接」 | 手机和电脑是不是同一个 Wi-Fi（热点也行） |
| 连接时报错 / 超时 | 电脑上的「允许局域网访问」开着没？Windows 防火墙要放行**专用网络** |
| 昨天能用今天不行 | 电脑换了网络 → IP 变了。电脑上重新开一次手机访问，拿新链接，App 里「换一台电脑」重新填 |
| 页面空白 | 电脑上的 AstrBot Chat / BFF 没在跑，或 AstrBot 本体没起来 |

## 4. 怎么用

| 界面 | 说明 |
|---|---|
| 会话列表 | 头像 + 名字 + 一行预览 + 时间；红点表示有未读 |
| 聊天 | 头部「返回 + 名字/在线 + ⋯」；`⋯` 里是 **记忆、聊天设置、换头像、更多设置** |
| 聊天设置 | 图片识别 / 语音消息 / 表情包 / 朗读回复 四个开关 |
| 设置 | 从 **左边缘往右滑** 呼出抽屉 → 点「设置」进全屏设置页（外观、聊天背景、机器人名字/头像都在这里） |
| 换一台电脑 | 抽屉里的「换一台电脑」，或设置 → 通用 → 换一台电脑 |
| 返回键 | 先关浮层 → 关抽屉 → 关设置 → 回会话列表；**在列表上再按一次才退出** |

> 备注 / 置顶 / 归档 / 删除这些会话管理按钮目前**只在桌面端**有（手机上被隐藏了）。
> 手机上要删会话，暂时用电脑；删除还需要电脑装了 `astrbot_plugin_webchat_admin` 插件。
