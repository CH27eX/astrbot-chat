## 一、聊天

| 功能 | 说明 | 位置 |
|---|---|---|
| 发文字 | 输入框跟随内容增高（44px 起，最高 148px，再多内部滚动）；`Enter` 发送、`Shift+Enter` 换行 | `ChatPanel.tsx` |

| 新建对话 | 首条消息发出后由服务端返回 `session_id`，自动切到该会话 | `App.tsx` `newChat()` |
| 历史消息 | BFF 直读 SQLite 取最近 200 条（API Key 读不到管理员会话详情） | `server/index.mjs` `handleHistory` |
| 加载更早 | 列表顶部按钮，一次再取 100 条；补历史时保持可视位置不跳；离屏消息用 `content-visibility` 跳过排版 | `ChatPanel.tsx` / `.msg` |

## 七、连接与运行方式

| 项 | 现状 |
|---|---|
| AstrBot 地址 | **默认全自动**：BFF 扫本机监听端口（Windows 走 PowerShell，Linux 读 `/proc/net/tcp`，Launcher 每次换端口也不影响）；也可在设置里填固定地址（云主机 / 另一台机器），保存后自动重启 BFF |
| 历史库 `data_v4.db` | **默认全自动**：①设置里填的「AstrBot 数据目录」最优先（支持 `~/...` 与 `$VAR`）；②从运行中的 AstrBot 实例推（Linux 读 `/proc/<pid>/cwd`+`cmdline`；Windows 读命令行，Launcher 风格则按 `dashboard.port` 对齐）；③常见布局：Launcher 实例、`~/astrbot/data`、`$XDG_DATA_HOME/astrbot/data`、`/opt/astrbot/data`。诊断：`http://127.0.0.1:8788/astrbot/api/db-status`（看 `source`：`settings`/`pid`/`port`/布局） |
| AstrBot 未启动 | **自动**拉起 Launcher（可关） |
| API Key | **首次需手填一次**（去 AstrBot 面板 API Keys 复制）；之后存 `settings.json`，重启/升级不丢 |
| Key 自动获取 ⚠️ | 做不到：库里只存 `key_hash`/`key_prefix`；`desktop-session` 免密通道拿不到 secret；现有 Key 无 `system` scope 不能自建 Key |
| 深链 / 二维码 | 深链未实现（只有内部事件名 `astrbot://close-requested`）；**配对二维码 0.2.12 起**：设置 → 桌面 → 手机访问，扫码即配对（60 秒自动收起，「重置配对」可换令牌） |
| BFF 监听 | 默认 `127.0.0.1:8788`（仅本机）；打开「允许局域网访问」后绑 `0.0.0.0:8788`（+ 自签 https `8789`），非回环请求必须带令牌 |
| 浏览器 PWA | `start-pocket.ps1`：Vite 5173（dev）/ 4173（预览），可「安装到桌面」，带 manifest + Service Worker；壳里不注册 SW |
| BFF 职责 | 端口自动发现、API Key 注入（不暴露给前端）、CORS、只读 SQLite 历史、会话摘要 |

**三种跑法**：装机版 `%LOCALAPPDATA%\AstrBot Chat`（主用法，壳托管 BFF）、浏览器 PWA、`tauri dev`。
⚠️ dev 的 `app.exe` 与安装版共用 WebView2 profile 和 `settings.json`，不能同时验两种状态。

## 十、本版边界（做不到 / 有条件）

| 想做的事 | 现状 / 原因 |
|---|---|
| 删除、重命名会话真正生效 | ⚠️ **装了 `astrbot_plugin_webchat_admin` 插件就能**（删会话、改服务端名）；没装则删除被 AstrBot 拒绝、改名只能本地备注（API Key 身份 `api_key:<id>` ≠ creator） |
| 远端 AstrBot 的历史记录 | ⚠️ 本地库读不到时，装了插件就改走插件读；没装就显示「无历史」 |
| 容器 / 另一台机器里的 AstrBot 历史 | ⚠️ BFF 只能看本机 `/proc` 和本机文件；AstrBot 在 Docker 或别的机器里时，要么把挂载出来的库目录填进「AstrBot 数据目录」，要么留空（显示无本地历史） |
| 删除 / 编辑正文 / 新建记忆 | 抽屉只做浏览 + ⭐ 标记（按需求不删除） |
| 跨会话的「全局消息搜索」在远端连接上 | 搜索只覆盖本地 SQLite；远端 / Docker 显示「读不到本地消息库」 |
| 主题浅色之外的自定义（字号单调、跟随系统） | 只有深/浅两套主题 + 两档密度 |
| 手机端录音 / 装 PWA | 条件：**先装一次自签 CA**，用 `https://<PC-IP>:8789`（安全上下文）打开；纯 http 源上 `mediaDevices` / `serviceWorker` 都不存在 |
| 手机端打开即用 | 0.2.12 起：打开「允许局域网访问」→ 手机同 Wi-Fi 扫设置页二维码即可（不用手打地址） |
| 自动更新真正可用 | 要先把 `latest.json` 传到 https 静态目录并在设置里填更新源 |
