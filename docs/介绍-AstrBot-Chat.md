# AstrBot Chat

**把 AstrBot 变成桌面上真正好用的聊天客户端。**

Windows / Linux 桌面应用，手机浏览器也能用。聊的还是你自己的 AstrBot —— 消息、记忆、和 QQ 里那套完全同一份。

![主界面](screenshots/main.png)

---

## 它解决什么问题

AstrBot 自带的面板是**管理后台**：配模型、装插件、看日志很顺手，但拿它当聊天工具用，会有三个绕不过去的问题：

1. **翻历史很痛苦** —— 长对话要一屏一屏往上滚，不能搜索，退出就回到最上面；
2. **没有会话管理** —— 不能置顶、归档、备注，几十个会话只能按时间排；
3. **手机上基本没法用** —— 面板布局不是为窄屏做的，输入框、键盘、刘海全都不对付。

AstrBot Chat 就是补上这三块：**一套按聊天软件做的界面**，直接读 AstrBot 的会话与本地历史库，不改变你现有 AstrBot 的任何配置。

## 主要功能

### 聊天

- **流式回复**：逐字出，带停止键；长回复不掉帧（每帧最多刷一次，只重绘最后一条）
- **Markdown**：代码块、列表、表格、链接都按聊天软件的样子渲染，带 token 数与耗时
- **图片 / 文件 / 视频 / 语音**：发送、预览、拖拽进窗口；表情包收藏与一键发送
- **朗读回复**（可选）：系统 TTS，只在最后一条回复完成时念一次

### 会话

- 摘要、置顶、归档、备注、行内改名
- 消息搜索（本地 SQLite，按关键词）
- 分批加载：本地库一次 200 条，往上翻再补，**翻历史时视口不跳**

### 历史与记忆

- **直接读 AstrBot 的 `data_v4.db`**：Windows / Linux 自动发现（设置目录 → 从运行实例推 → 常见安装布局），不用手动填路径
- 诊断端点 `/astrbot/api/db-status` 会说清楚「读的哪个库、怎么推出来的」
- **记忆抽屉**：支持 Memory Beyond / LivingMemory / Memory Companion / Angel Memory 四家，按来源切换；MC 的 ⭐ 在打补丁 + 开开关后可以直接点

### 桌面体验

- 无边框窗口、单实例、开机自启、关闭时询问（托盘 / 退出）
- 深色 / 浅色主题、强调色、字号档、圆角档、聊天背景图库
- 托盘常驻，窗口状态记忆

### 连接

- 默认**全自动**：扫描本机端口找 AstrBot（Launcher 每次换端口也不影响）
- 也可以填远端地址（云主机 / 另一台机器），保存后自动重启服务
- **API Key 体检**：直接告诉你 Key 是无效、缺 `chat` 还是缺 `plugin` scope

### 手机

同一个 Wi-Fi，**扫一下设置页的二维码**就能用，不用手打地址：

![配对二维码](screenshots/pairing.png)

- 二维码 60 秒自动收起（防止截图把访问令牌带走）；手机丢了点「重置配对」，旧链接全部失效
- 第一次要装一次自签证书（安卓「安装 CA 证书」，iOS 再开「完全信任」），之后才有 HTTPS、录音和「添加到主屏幕」
- 手机布局专门调过：没有窗口按钮、工具收进「＋」、输入框贴键盘、刘海和手势条留出安全区

## 三步开始

1. **装**：Windows 双击 `AstrBot Chat_0.2.17_x64-setup.exe`（SmartScreen 提示时点「更多信息 → 仍要运行」）；Linux `sudo apt install "./AstrBot Chat_0.2.17_amd64.deb"`；
2. **填 Key**：打开应用 → 左下角「设置 → 桌面」→ 粘贴 AstrBot 面板里建的 API Key（勾 `chat` + `file`，要用记忆抽屉再勾 `plugin`）；
3. **聊**：AstrBot 在同一台机器上，「AstrBot 地址」留空即可（自动发现）；在另一台就填 `http://那台机器:端口`。

详细步骤见同包的 `安装引导.md`。

## 系统要求

| 项 | 要求 |
|---|---|
| 桌面系统 | Windows 10 / 11 x64；Ubuntu 24.04+ / Debian 12+（amd64） |
| AstrBot | v4.x（需要面板可访问；记忆抽屉另需对应记忆插件） |
| API Key | scope 至少 `chat` + `file`；要记忆 / 会话管理增强再加 `plugin` |
| 运行时 | 客户端**自带 Node**，不需要另装 |
| 网络 | 本机使用不需要联网；手机访问需要同一 Wi-Fi |

## 隐私与安全

- **Key 不进前端**：API Key 只存在本机的 `settings.json` 里，由本地服务（BFF）注入请求，网页侧永远拿不到；
- **不做云端**：没有账号、没有遥测、没有中转服务器，消息直接打到你的 AstrBot；
- **局域网有门**：打开「允许局域网访问」后，非本机请求必须带令牌；令牌换 cookie 后从地址栏消失；
- **HTTPS 是自签的**：证书只在本机生成，手机装一次即可；证书私钥不出本机。

## 已知限制

1. Windows 安装包**没有代码签名** → SmartScreen 会提示，点「更多信息 → 仍要运行」即可；
2. **自动更新还没启用** → 新版本要手动装安装包（升级会保留设置与 Key）；
3. 客户端**不带 AstrBot**，它只是客户端；AstrBot 需要你自己跑着；
4. 客户端读的是**本机**的 `data_v4.db`：AstrBot 在 Docker / 另一台机器时，历史要么靠装 `astrbot_plugin_webchat_admin` 插件，要么把手挂出来的库目录告诉客户端；
5. Linux 二进制名：0.2.14 起是 `/usr/bin/astrbot-chat`（0.2.13 及更早是 `/usr/bin/app`）；
6. Win11 把托盘图标折进「^」时点不出来（救急：再启动一次应用会把窗口唤回来；缩到托盘时也会提示一次）；
7. macOS 暂不支持。
