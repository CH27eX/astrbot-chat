# 从源码构建与开发

这份文档面向想改代码 / 自己出包的人。只想安装使用，请看 `安装配置指南-0.2.26.md`。

## 1. 需要什么

| 目标平台 | 需要的工具 |
|---|---|
| 前端 / 全部 | Node.js **20+**（推荐 24）、pnpm 9+ |
| Windows 安装包 | Rust stable + MSVC 生成工具 + WebView2（Win10 1809+ 自带） |
| Linux 安装包 | Rust stable、`libwebkit2gtk-4.1-dev`、`libgtk-3-dev`、`libayatana-appindicator3-dev`、`dpkg-deb` |
| Android APK | JDK 21、Android SDK（build-tools 35、platform 36）、本机 keystore |
| iOS ipa | **macOS** + Xcode 15+（Windows / Linux 无法编译） |

> 交叉编译不在支持范围内：Windows 包在 Windows 上打，Linux 包在 Linux（或 WSL2 Ubuntu 24.04）里打。

## 2. 起步

```bash
pnpm install
cp .env.example .env.local     # 填 ASTRBOT_API_KEY；地址一般留空自动发现
pnpm dev                       # BFF(8788) + Vite(5173)
```

浏览器打开 <http://127.0.0.1:5173>。生产构建：

```bash
pnpm build                     # tsc --noEmit + vite build → dist/
pnpm test:unit                 # node --test + ps1 编码检查
pnpm smoke                     # 可选：构建产物冒烟
```

## 3. 桌面端（Tauri）

```bash
# 开发（热更新）
node node_modules/@tauri-apps/cli/tauri.js dev

# Windows 安装包（NSIS）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/release.ps1

# Linux deb（在 Linux / WSL 里）
cargo tauri build --bundles deb --config src-tauri/tauri.deb.conf.json
```

注意事项：

- `scripts/release.ps1` 需要更新签名私钥（`TAURI_SIGNING_PRIVATE_KEY` +
  密码文件，默认在 `~/.astrbot-updater/`），没有就改用普通 `tauri build`；
- `src-tauri/resources/bff/`、`src-tauri/resources/node/` 是打包时生成的
  （`scripts/sync-sidecar.mjs`），仓库里没有：Windows 要自己放 Node 24 的 `node.exe`
  到 `src-tauri/resources/node/`，Linux / macOS 会在构建时复制当前 node；
- Linux 的 `tauri.deb.conf.json` 只是把 `beforeBuildCommand` 置空（WSL 里没 node），
  前端要先在宿主机 `pnpm build` 再把 `dist/` 同步过去；
- **WSL 里构建时不要把 `src-tauri/resources/node` 换回 Windows 版**，否则 deb 里会带一个 `.exe`。

## 4. Android

```bash
pnpm build
node node_modules/@capacitor/cli/bin/capacitor sync android
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/android-release.ps1 -SkipFrontend
```

- 签名材料在 `~/.astrbot-android/`（`astrbot-chat-release.jks` + `keystore.properties`），
  第一次运行脚本会自动生成；**同一把 key 才能覆盖升级**；
- 自检：`android/app/src/main/assets/capacitor.plugins.json` 里应有 `@capacitor/app`；
- 图标 / 启动图：`python scripts/android-icons.py`（源图 `src-tauri/icons/icon.png`）。

## 5. iOS

```bash
node node_modules/@capacitor/cli/bin/capacitor sync ios
bash scripts/build-ios.sh                 # 需要 macOS + Xcode
```

- 工程用 **SPM**（不是 CocoaPods），`ios/App/CapApp-SPM/Package.swift` 由 `cap sync ios` 生成，
  里面的本地依赖指向 `node_modules/.pnpm/...`，所以换机器要先 `pnpm install`；
- 图标 / 启动图：`python scripts/ios-icons.py`；
- 详细步骤见 `docs/TESTER-GUIDE-IOS.md`。

## 6. 目录结构

```
src/              前端（React + TS）
  core/           传输层、IndexedDB、偏好、PWA
  components/     侧栏 / 聊天 / 设置 / 气泡
  styles.css      基础样式与主题变量
server/index.mjs  本地 BFF：鉴权注入、SSE 透传、历史库只读、局域网 HTTPS / 配对
src-tauri/        桌面壳（Rust）+ 打包配置
android/          Capacitor Android 工程
ios/              Capacitor iOS 工程（SPM）
scripts/          构建 / 打包 / 图标 / 开发工具
docs/             接口规范、方案、测试须知
```

## 7. 常见坑

1. **PowerShell 5.1 与编码**：仓库里的 `.ps1` 必须 UTF-8 **带 BOM**，否则中文按 ANSI 读会语法报错；
   `pnpm test:unit` 会跑 `scripts/check-ps1-encoding.mjs` 检查。
2. **写 `package.json` / `keystore.properties` 不要带 BOM**：前者会让 Vite 报 `Unexpected token`，
   后者会让 Gradle 读不到 `storeFile`（打出来是 unsigned apk）。
3. **pnpm store 不一致**：`ERR_PNPM_UNEXPECTED_STORE` 时加 `--store-dir <原来的 store>`，
   或删掉 `node_modules` 用当前 store 重装。
4. **改 `server/index.mjs` 要重启 BFF**（`pnpm dev` 会一起重启）。
5. **`cap sync` 会覆盖 `android/app/src/main/assets/public`、`ios/App/App/public`**，
   别在里面手改东西。
